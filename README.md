## Culver City Coalition

The **Culver City Coalition (CCC)** is a resident-driven Political Action Committee focused on Culver City local government, public information, resident participation, and what CCC describes as **good governance, transparency, and common sense**.

This repository exists to support the public GitHub organization profile for CCC.

### Public information

- Website: **[culvercitycoalition.org](https://www.culvercitycoalition.org/)**
- Articles and updates: **[culvercitycoalition.org/articles](https://www.culvercitycoalition.org/articles)**
- PAC identification: **FPPC #1446843**

Most operational repositories in this organization are private.
